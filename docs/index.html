Recognises what you have

Strips release junk from cryptic filenames, then confirms the title, year, season and episode against TMDB — with a review queue for anything uncertain, never a silent guess.

Posters as folder icons

Every folder gets the real poster as its Windows icon — three styles, your own colour per film or series, borders and corners to taste.

Subtitles, matched or fetched

How it works

Four steps, and none of them touch a file without asking.

1

Point it at a folder

Downloads, a USB drive, anywhere. Cinefold reads every video and subtitle inside — it changes nothing yet.

2

Review what it found

Confident matches sit in Ready. Anything unsure waits for you, with a search box to pick the right title yourself.

3

Preview the library

Every file's exact destination, side by side. Untick anything. This is the last chance before anything moves.

4

Done — with posters

Files are filed, subtitles matched, and every folder gets its poster as a Windows icon. Undo is one click away, always.

Get started

Three things, and you're organising. All free, no card required.

1

Download and run Cinefold

Grab the installer from the Releases page and run it. Cinefold is unsigned, so Windows SmartScreen will warn on first launch — that's expected for a small open-source tool; click More info → Run anyway.

2

Get a free TMDB key

Cinefold uses TMDB to recognise titles and fetch posters. Sign up (free), then open Settings → API and request a key — it's issued instantly. Paste it into Cinefold's Settings → Library tab.

3

Pick a library folder

Choose an empty folder (or an existing library) as the destination in Settings → Library. Point Cinefold at your messy downloads folder, hit Scan, and preview your new library.

+

Optional: subtitles on demand

Want Cinefold to fetch missing subtitles too? Grab a free key from SubDL (your profile → API Key) and add it in Settings. Nothing downloads automatically unless you turn that on — otherwise it's a one-click "Get subtitle" whenever you actually want one.

Building from source instead?

Cinefold is Tauri + Rust + React. Prerequisites, build steps and the full architecture are in the repo README.
